## 0. Честная рамка: чем это НЕ является

Спека 0001 убила XS momentum/carry на топ-ликвидных перпах. Эта спека — не
«дожать те же сигналы до PASS», а проверка отдельной гипотезы о том, ГДЕ такие
премии могут существовать. Правила против самообмана:

- **Одна попытка.** Это последний тест XS-направления. KILL здесь = направление
  закрыто целиком, без «а давай ещё 12h / ещё квантиль».
- Грид заморожен до данных; N честно в DSR.
- **Кросс-спековая множественность:** если что-то пройдёт пороги, дополнительная
  проверка чувствительности — DSR с N = 36 (спека 0001) + N этой спеки. PASS,
  не переживающий объединённый N, понижается до «слабый кандидат», не в paper.

## 1. Гипотеза H3 (зафиксирована до данных)

Premia относительной силы и funding-спреда не выживают в топе ликвидности,
потому что там их выедает арбитражный капитал (0001 это измерил). В середине и
хвосте ликвидности конкуренция тоньше: ротация капитала медленнее, экстремумы
funding глубже и живут дольше, а ёмкость стратегий слишком мала, чтобы крупные
игроки их выравнивали. Если XS-premia существуют где-то — то здесь; плата —
худшее исполнение, которое моделируем честно (slippage выше, чувствительность
к его удвоению обязательна).

## 2. Данные и universe (главные отличия от 0001)

- **Таймфрейм 1d**, окно **30 полных месяцев** (2024-01…2026-06, ~910 баров):
  на дневной сетке баров мало, тест теряет мощность — покупаем её длиной окна.
- **Кандидаты: ВСЕ USD-M перпы, когда-либо имевшие дампы** — перечень берём из
  S3-листинга data.binance.vision (включает делистнутые). Это убирает
  survivorship-bias кандидатского уровня, который в хвосте ликвидности был бы
  огромным (делистинги там — норма). Bias пула из 0001 v1.1 здесь устранён.
- **Universe point-in-time, помесячно:** ранжируем по медианному дневному
  quote-объёму за прошлые 30 дней; берём **ранги 21–80** (60 имён):
  топ-20 исключён (там 0001 уже показал отсутствие edge, и их присутствие
  разбавило бы хвостовой сигнал), низ отсечён **полом ликвидности
  ≥ $5M медианного дневного объёма** (иначе slippage-модель фикция).
  Мин. история листинга 90 дней — как в 0001.
- Funding: реальная история по каждому символу; на дневном баре — сумма
  платежей дня (floor-выравнивание уже так работает). funding=0 ⇒ carry
  недостоверен ⇒ прогон невалиден.

## 3. Издержки (жёстче, чем в 0001)

- Тейкер 5 bps + **slippage 5 bps** на сторону на ногу (хвост ликвидности).
- Обязательный стресс: slippage 10 bps — вердикт PASS обязан выживать.
- Оборот по Σ|Δw_i|, как в 0001.

## 4. Сигналы и грид (заморожен; N в DSR)

Дельта-нейтрально: +0.5 лонги / −0.5 шорты, равновзвешенно внутри стороны.
Ребаланс и сигналы в дневных барах.

**XS-momentum (24):** lookback L ∈ {7, 14, 30}д; skip s ∈ {0, 1}д;
квантиль q ∈ {20%, 25%} (12 или 15 имён на сторону из 60); ребаланс R ∈ {1, 7}д.

**XS-carry (12):** окно среднего funding F ∈ {3, 7, 14}д; q ∈ {20%, 25%};
R ∈ {1, 7}д.

## 5. Валидация (судья без изменений)

CPCV S=10, k=2, purge=1, embargo=31 бар (max lookback+skip); вердикт по
медианному из 9 путей, worst path в отчёт. DSR (точная V, N=24/12 по семейству;
для PASS — доп. проверка с объединённым N по §0). PBO (CSCV, 10 блоков).
Пороги прежние: сделки ≥ 200, OOS Sharpe > 0.7, MDD < 20%, DSR ≥ 0.95.

## 6. Kill-критерии и стресс выжившего

KILL при провале любого порога медианным путём. Для PASS: плато ±1 шаг;
разбивка по годам; slippage ×2 (обязательный, §3); PBO < 0.5; объединённый N.
Хрупкий = KILL «хрупок». После вердикта — СТОП; paper/live только отдельным
решением владельца при робастном PASS.

## 7. Инженерные дельты

1. Перечень символов из S3-листинга бакета (пагинация list-type=2) — новый
   `list_all_um_symbols()` в data.py.
2. Панель 1d: ~500+ символов × 30 мес — тяжёлая первичная загрузка (часы),
   полностью кэшируется; `--pool-cap` для отладочных прогонов.
3. Universe-band (ранги 21–80 + пол $5M) — расширение monthly_universe
   (параметры skip_top, min_median_qv).
4. Funding на дневной бар = сумма платежей дня — уже работает (floor+sum).
Судья, движок, веса — без изменений.

## 8. Вне скоупа

Ликвидационные каскады, межбиржевой базис, интрадей-исполнение, paper/live.

## 9. Критерий успеха

Спека realised, когда оба семейства получили вердикт при валидном funding и
подтверждённом отсутствии survivorship-bias кандидатского уровня (перечень
символов реально включает делистнутые — проверить и залогировать их долю).
KILL закрывает всё XS-направление; следующая спека — только новый механизм
(каскады / межбиржевой базис).

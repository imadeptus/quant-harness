## 1. Гипотеза H4 (зафиксирована до данных)

Один и тот же перп на разных биржах имеет устойчиво разный funding: клиентела
и плечо различаются (ритейл-лонги распределены неравномерно), а арбитраж между
площадками ограничен капиталом, комиссиями и лимитами. Пара «лонг там, где
funding дешевле / шорт там, где дороже» на ОДИН underlying:
- ценовой риск ≈ 0 по построению (обе ноги трекают один индекс);
- PnL = funding-спред − издержки входа/выхода/переворотов − дрейф венью-базиса.
Если спред персистентен (часы–дни), он собираем после 4-ногих издержек.

Фальсификация: медианный CPCV-путь не проходит пороги ⇒ KILL, гипотеза закрыта.

## 2. Данные

- Binance: funding + 1d klines — уже в harness (кэш).
- Bybit: `GET /v5/market/funding/history` (funding, 200/стр., глубина
  подтверждена разведкой) и `GET /v5/market/kline` (1d closes для честного
  учёта дрейфа базиса между ногами). Кэшируются как parquet.
- Окно: 2024-01…2026-06 (30 мес), сетка 1d; funding агрегируется в день
  (floor+sum, как в harness).
- Universe: пересечение листингов Binance∩Bybit; point-in-time топ-20 по
  30-дневному объёму Binance (механизм из 0001/0002; исполнение 4-ногое,
  поэтому только ликвидный сегмент); мин. история 90д.

## 3. Конструкция и издержки

- Сигнал по символу: скользящее среднее дневного спреда
  Δf = funding_binance − funding_bybit за окно W.
- Позиция: если |Δf̄| > θ — пара весом 1/n_active (равновзвешенно по активным
  символам, гросс 1.0): знак так, чтобы ПОЛУЧАТЬ спред (шорт дорогой ноги).
- PnL пары за день: w · [sign·(r_bybit − r_binance) + sign·(f_binance − f_bybit)]
  (ценовые ноги почти гасятся — остаток и есть венью-базис, учитываем честно).
- Издержки: 4 ноги × (5 bps taker + 2 bps slippage) на вход и на выход;
  переворот = выход+вход. Ликвидный сегмент ⇒ 2 bps slippage, но стресс
  ×2 обязателен для PASS.

## 4. Грид (заморожен; N=18 в DSR)

- Окно W ∈ {3, 7, 14} дней;
- Порог θ ∈ {0, 0.00005, 0.0001} на 8h-период (≈ 0 / 5.5% / 11% годовых);
- Ребаланс R ∈ {1, 7} дней.
  Итого 3 × 3 × 2 = 18 конфигураций.

## 5. Валидация (судья без изменений)

CPCV S=10, k=2, purge=1, embargo=14 баров; вердикт по медианному из 9 путей.
DSR: точная V, N=18. PBO (CSCV, 10). Пороги прежние (сделки ≥ 200 — ноги пар,
OOS Sharpe > 0.7, MDD < 20%, DSR ≥ 0.95). Funding обеих бирж обязан покрывать
≥ 90% member-баров, иначе прогон невалиден.

## 6. Kill и стресс выжившего

KILL при провале любого порога. Для PASS: slippage ×2; плато ±1 шаг; разбивка
по годам; PBO < 0.5; DSR с объединённым N (36+36+18) как чувствительность.
Хрупкий = KILL. После вердикта СТОП; paper/live — отдельное решение владельца.

## 7. Инженерные дельты

1. `bybit.py`: funding-история и 1d klines с parquet-кэшем (пагинация, без
   silent-фолбэков; символы Bybit linear = те же тикеры USDT).
2. Спред-движок пар: активация по θ, веса, 4-ногие издержки, венью-базис.
3. Пресет 0003 в run_xs.py (или отдельный run_basis.py) поверх run_cpcv_returns.

## 8. Вне скоупа

Каскады (нет свободных данных), OKX (глубина), интрадей-исполнение, paper/live.

## 9. Критерий успеха

Вердикт обоих порогов покрытия данных: funding-покрытие ≥ 90% на обеих биржах
залогировано; вердикт PASS/KILL получен. KILL ⇒ гипотеза закрыта, направление
«межбиржевой базис» не перекручивается другими парами бирж без новой экономики.

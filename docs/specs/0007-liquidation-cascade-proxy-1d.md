## 0. Почему прокси и почему это новый механизм

Пользователя интересуют ликвидационные каскады; настоящие данные ликвидаций
платные/за-ключом (нельзя автономно). Но каскад НАБЛЮДАЕМ в цене: массовая
ликвидация = резкое однобарное движение + всплеск объёма. Тестируем tradeable-
версию: **fade экстремального объёмо-подтверждённого бара**. Это НЕ XS-carry/
momentum (0002/0006) и НЕ медленный mean-reversion из KILL-1 (там непрерывный
z-score по окну) — здесь СОБЫТИЙНЫЙ сигнал, обусловленный одним шок-баром с
подтверждением объёмом. Экономика: ликвидационный овершут откупается.

Оговорка честности: механизм соседствует с mean-reversion; отличие —
событийность (один бар-шок) + условие на объём (у ликвидации всегда всплеск).
Если KILL — прокси-версию каскад-реверсала закрываем; настоящие данные
ликвидаций (платно) могли бы сказать больше, но это уже отдельное решение.

## 1. Гипотеза H7 (до данных)

После бара с экстремальным движением (|ret| > k·σ) И всплеском объёма
(vol > m·медиана) цена на следующих барах откупается в обратную сторону
(овершут от вынужденных ликвидаций). Кросс-секционно, дельта-нейтрально:
лонг тех, кого вчера залили вниз на объёме; шорт тех, кого загнали вверх.

## 2. Данные (100% из кэша, 0 загрузок, 0 решений)

## 3. Сигнал и грид (заморожен; N=12, честно в DSR)

На баре t (решение по t−1, held с t+1 — анти-look-ahead движка):
- ret = close-to-close бара t−1; σ = std ret за trailing окно (30д);
- vol_spike = quote_volume(t−1) / медиана quote_volume за 30д;
- shock_down = ret < −k·σ И vol_spike > m → вес +1 (fade вверх);
- shock_up = ret > +k·σ И vol_spike > m → вес −1;
- держим H баров, равновзвешенно, дельта-нейтрально (гросс 1.0), нормировка.

Грид: k ∈ {2, 3}; m ∈ {2, 3}; H ∈ {1, 3, 7}. Итого 2×3... = **12** конфигов.

## 4. Издержки

Шок-бары часто в тонких именах → тейкер 5 bps + slippage 10 bps на сторону на
ногу; стресс ×2 обязателен для PASS. Funding реальный на ноги.

## 5. Валидация + ГРОМКИЕ гарды (критично для ночного автономного прогона)

Судья без изменений: CPCV S=10 k=2 purge=1 embargo=30; медианный путь; DSR
(точная V, N=12); PBO. Пороги прежние. Позитивный контроль судьи уже есть.

**Гарды валидности (пишутся в отчёт, KILL с гардом ≠ чистый KILL):**
- funding-покрытие member-баров логируется; carry-компонента тут вторична.
- **shock-событий** в OOS ≥ 200 (иначе `trades_ok`=False честно ловит).
- доля member-баров с данными; если сигнал вырождается (0 позиций) — флаг в отчёт.
Никаких тихих нулей: любая вырожденность → явный warning в JSON, не молчаливый KILL.

## 6. Kill и стресс

KILL при провале любого порога. Для PASS: slippage ×2; плато ±1 шаг по k/m/H;
режимы по годам; PBO < 0.5; суммарный N. Хрупкий = KILL. Стоп; никакого
paper/live.

## 1. Зачем это новая экономика (а не пятая перекрутка)

Специи 0001-0003 убили сигналы из цены и funding. Здесь сигнал — **из события**:
факт и возраст листинга перпетуала. Это ортогонально предыдущему: не «куда пойдёт
цена по своей истории», а «ведут ли себя недавно листнутые контракты системно
иначе, чем зрелые». Механизм ≠ прошлые, поэтому это не data mining на убитой идее.

## 2. Гипотезы (зафиксированы до прогона)

**H5-drift.** Листинг перпа = приток внимания и потоков (индексные боты, ретейл,
маркет-мейкеры набирают инвентарь). Молодые контракты первые недели дрейфуют
вверх относительно рынка. Лонг корзины молодых, хедж рынком.

**H5-reversal.** Альтернатива: листинг = разовый памп с последующим затуханием
(ранняя переоценка, разлок ликвидности М', выход инсайдеров). Молодые контракты
первые недели отстают. Шорт корзины молодых, хедж рынком.

Гипотезы взаимоисключающие по знаку — грид тестирует обе, DSR штрафует за то,
что мы попробовали оба направления (N суммарный). Побеждает та, что переживёт
пороги; если ни одна — эффекта нет, KILL.

## 3. Данные (всё из кэша, 0 новых загрузок)

- Панель 1d, 2024-01…2026-06, пул 790 перпов из S3-листинга (кэш 0002),
  делистнутые включены (survivorship закрыт).
- Дата листинга символа = первый бар в кэше; **возраст(t) = t − дата листинга**.
- Бенчмарк-хедж: равновзвешенная корзина «зрелых» перпов (возраст > 180д) —
  как рыночная бета для дельта-нейтральности. Хедж-нога несёт свои издержки.
- Funding реальный (кэш), начисляется на обе ноги.

## 4. Анти-look-ahead и селекция (критично для event-study)

- Первый торгуемый бар символа — **листинг + 1** (на самом баре листинга не
  торгуем: возраст 0 недоступен на его же закрытии). Позиция t = сигнал t−1
  (движок уже так делает).
- В корзину на день t входят символы с **возрастом ∈ [E_start, H]** ПО ДАННЫМ,
  известным на t−1. Никакого знания будущей делистинг-даты.
- Пол ликвидности $2M медианного дневного объёма за доступное окно (молодой перп
  может быть неликвиден — иначе slippage фикция). Меньше истории, чем окно, —
  берём что есть, но не менее 3 баров.

## 5. Издержки (жёстче: молодые контракты)

- Тейкер 5 bps + **slippage 10 bps** на сторону на ногу (молодые перпы волатильны
  и тоньше). Хедж-нога — 5+2 bps (зрелый ликвидный бенчмарк).
- Стресс ×2 по slippage обязателен для PASS.
- Оборот по Σ|Δw| (вход/выход молодых по мере пересечения границ возраста).

## 6. Грид (заморожен; N=12 суммарно, по 6 на направление)

Обе семьи (drift = знак +1 на корзину молодых, reversal = −1):
- E_start ∈ {1, 3} дн (пропуск самого первого дня против листинг-иглы);
- H (верхняя граница возраста) ∈ {7, 14, 30} дн;
- ребаланс 1 дн (fixed); вес равный внутри корзины, гросс 1.0, хедж −1.0 рынком.
  6 конфигов × 2 направления = 12.

## 7. Валидация (судья без изменений)

CPCV S=10, k=2, purge=1, embargo=30 (max H); вердикт по медианному из 9 путей.
DSR: точная V, N=6 на направление; для PASS — чувствительность с суммарным
N=12 (обе семьи) и кросс-спековым (0001-0003). PBO (CSCV, 10).
Пороги прежние: сделки ≥ 200, OOS Sharpe > 0.7, MDD < 20%, DSR ≥ 0.95.
Покрытие funding ≥ 90% member-баров, иначе carry-компонент помечается.

## 8. Kill-критерии

KILL при провале любого порога медианным путём. Для PASS: slippage ×2; плато
±1 шаг по E_start/H; разбивка по годам (2024/2025/2026); PBO < 0.5; суммарный N.
Хрупкий = KILL «хрупок». После вердикта — СТОП; paper/live только отдельным
решением владельца при робастном PASS.

## 9. Инженерные дельты

1. `listing.py`: даты листинга из кэша, матрица возраста, построение корзины
   «молодые ∈ [E,H]» + бенчмарк «зрелые >180д», хедж-веса.
2. Переиспользовать run_xs_backtest (веса + хедж — просто ещё столбцы весов) и
   run_cpcv_returns. Судья не трогается.
3. Пресет 0004 в оркестраторе.

## 10. Вне скоупа

Ликвидации/каскады (платно), интрадей-исполнение, разлоки токенов (нужен
отдельный источник дат разлока), paper/live.

## 11. Критерий успеха

Realised, когда обе семьи получили вердикт при валидном покрытии данных и
подтверждённом отсутствии look-ahead (первый бар = листинг+1, инклюзия по t−1).
KILL закрывает пост-листинговый эффект; следующее — только новый механизм или
платные данные (путь 1).
